# Tableau Sales Dashboard

An interactive Tableau dashboard built to analyze sales performance, profitability, customer segments, and product trends. This project demonstrates data visualization, dashboard design, KPI analysis, and business storytelling using Tableau.

## Features
- KPI Cards (Sales, Profit Margin, Return Rate)
- Monthly Sales Trend Analysis
- Sales by State
- Sales by Customer Segment
- Sales by Product Category & Sub-Category
- Top Performing Products
- Interactive Filters and Parameters
- Pie Charts, Histograms, and Line Charts

## Tools Used
- Tableau
- Data Visualization
- Dashboard Design
- Business Analytics

## Business Insights
- Identified top-performing products and regions.
- Compared sales performance across customer segments.
- Analyzed monthly sales trends.
- Evaluated profitability and return rates.
- Created an interactive dashboard for business decision-making.
